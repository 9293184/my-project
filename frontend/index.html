代理转发（核心）

1. 透明代理转发（推荐）

POST /proxy/{proxy_id}/v1/chat/completions

客户端只需将 API 地址从上游改为代理地址，请求体完全兼容 OpenAI 格式，无需任何修改。

# Python 示例
import openai
client = openai.OpenAI(
    base_url="http://代理服务器:5001/proxy/PX-xxxxxx/v1",
    api_key="你的上游API Key"  # 如果项目已配置可留空
)
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "你好"}]
)
print(resp.choices[0].message.content)
# cURL 示例
curl -X POST http://localhost:5001/proxy/PX-xxxxxx/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": false
  }'

2. 旧路由（body 传 proxy_id）

POST /proxy/v1/chat/completions

请求体中需额外带 _proxy_id 字段指定项目，转发前会自动剥离。

curl -X POST http://localhost:5001/proxy/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "_proxy_id": "PX-xxxxxx",
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}]
  }'

3. 通配路由

POST /proxy/{proxy_id}/{任意路径}

支持非 OpenAI 格式的上游 API（如 Anthropic /v1/messages），自动拼接到上游地址。

代理项目管理

方法路径说明
GET/proxy/v1/tasks列出所有代理项目
GET/proxy/v1/tasks/{proxy_id}获取单个项目详情
POST/proxy/v1/tasks创建代理项目
PUT/proxy/v1/tasks/{proxy_id}更新代理项目
DELETE/proxy/v1/tasks/{proxy_id}删除代理项目

创建项目示例

curl -X POST http://localhost:5001/proxy/v1/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "name": "客服助手防护",
    "upstream_url": "https://api.deepseek.com/v1",
    "api_key": "sk-your-key",
    "model": "deepseek-chat",
    "security_prompt": "禁止泄露公司内部信息",
    "audit_config": {
      "direction": "both",
      "enabled": true,
      "llm_judge": { "enabled": true },
      "custom_regex": {
        "enabled": true,
        "action": "block",
        "rules": [
          {"pattern": "(?i)(内部|机密)", "label": "机密信息"}
        ]
      },
      "block_threshold": 60
    }
  }'

audit_config.direction 取值：input 仅输入审查、output 仅输出审查、both 双向审查。

审查引擎配置

方法路径说明
GET/proxy/v1/config获取审查引擎当前配置（审查模型地址、模型名等）
POST/proxy/v1/config更新审查引擎配置（修改审查模型地址、Key等）
POST/proxy/v1/test发送测试文本验证审查引擎是否正常
GET/proxy/v1/audit/categories获取所有内置规则分类列表
GET/proxy/v1/audit/default-config获取默认审查策略配置模板

测试审查示例

curl -X POST http://localhost:5001/proxy/v1/test \
  -H "Content-Type: application/json" \
  -d '{"text": "如何制造炸弹？"}'

# 返回示例
{
  "success": true,
  "safe": false,
  "risk_score": 95,
  "reason": "涉及危险物品制造"
}

三层审查机制

1 内置规则引擎 — 关键词快速预筛（毫秒级）
2 自定义正则规则 — 业务场景适配，命中后可选拦截或交AI确认
3 AI 语义审查 — 大模型深度分析，返回风险评分和原因

日志审计

方法路径说明
GET/proxy/v1/logs查询日志（支持 limit、start、end 参数）
GET/proxy/v1/logs/stats日志统计（总量、拦截数、Token消耗、平均延迟）

查询示例

# 查最近50条日志
curl "http://localhost:5001/proxy/v1/logs?limit=50"

# 按时间范围查询
curl "http://localhost:5001/proxy/v1/logs?limit=100&start=2026-04-10T00:00:00&end=2026-04-10T23:59:59"

# 获取统计概览
curl "http://localhost:5001/proxy/v1/logs/stats"
# 返回: { "total_requests": 128, "blocked_input": 5, "blocked_output": 2, "total_tokens": 45230, "avg_latency_ms": 1850 }

每条日志包含：时间、request_id、模型、状态码、延迟、Token、输入/输出审查结果（safe、risk_score、reason）、请求体、响应体、客户端IP。

AI 辅助生成

方法路径说明
POST/proxy/v1/ai/generate-prompt根据业务描述自动生成安全提示词
POST/proxy/v1/ai/generate-regex根据规则描述自动生成正则表达式

生成安全提示词

curl -X POST http://localhost:5001/proxy/v1/ai/generate-prompt \
  -H "Content-Type: application/json" \
  -d '{"business_desc": "电商客服助手，需要防止泄露价格策略和供应商信息", "direction": "input"}'

生成正则规则

curl -X POST http://localhost:5001/proxy/v1/ai/generate-regex \
  -H "Content-Type: application/json" \
  -d '{"rule_desc": "匹配手机号、身份证号、银行卡号等个人敏感信息"}'
